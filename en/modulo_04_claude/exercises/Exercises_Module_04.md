### Exercise 1.2: Progressive Questions

Send these questions one at a time, in order:

**Level 1 — Comprehension:**
```
What are the 5 most important points of this document?
```

**Level 2 — Specific Search:**
```
What does the document say about [SPECIFIC TOPIC]?
Quote the relevant passages.
```

**Level 3 — Critical Analysis:**
```
Are there any ambiguities, contradictions, or gaps in the document?
If so, list them with the reference to the section.
```

**Level 4 — Application:**
```
Based on this document, create an operational checklist
of 10 items for [ROLE/ACTIVITY].
```
