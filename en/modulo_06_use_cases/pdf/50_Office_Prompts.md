# 50 Prompts for the Office

**AI Basics Course — Module 6**
*Ready-to-use collection for everyday work*

---

## How to use this collection

Each prompt is ready to copy and paste. Replace the placeholders in [BRACKETS] with your own data. Works with ChatGPT, Claude, and most open models.

## Communication (1-15)

### 1. Reply to a received email
```
I received this email: "[PASTE EMAIL]"
Write a reply that [GOAL].
Tone: [formal/friendly/assertive]. Max 150 words.
```

### 2. Follow-up email
```
Write a polite follow-up email to [NAME/ROLE].
Context: [SITUATION, e.g.: I sent them a proposal 5 days ago].
Goal: to obtain [WHAT]. Tone: professional but not pushy.
Max 100 words.
```

### 3. Payment reminder
```
Write a payment reminder for invoice no. [NUM] of [AMOUNT]
due on [DATE]. First reminder: polite and collaborative tone.
Mention the payment methods. Max 120 words.
```

### 4. Company introduction email
```
Write an introductory email for our company [NAME]
to a potential client in the [INDUSTRY] sector.
Main services: [LIST]. Propose an introductory meeting.
Tone: professional, value-oriented. Max 200 words.
```

### 5. Post-meeting thank you
```
Write a thank-you email after a meeting with [WHO].
Summarize the key points discussed: [POINTS].
Confirm the next steps: [ACTIONS]. Max 150 words.
```

### 6. Internal communication (announcement)
```
Write an internal announcement to communicate [NEWS] to the team.
Details: [WHAT IS CHANGING, WHEN, WHY].
Tone: positive and clear. Include FAQ: anticipate 3 questions.
Max 250 words.
```

### 7. Polite refusal
```
Write an email to politely decline [REQUEST/PROPOSAL].
Reason: [WHY]. Suggest an alternative if possible.
Tone: respectful and professional. Max 100 words.
```

### 8. LinkedIn post
```
Create a LinkedIn post about [TOPIC]. Target: [WHO].
Style: [storytelling / statistical data / list / open question].
120 words. Opening hook + final CTA + 3 hashtags.
```

### 9. Internal newsletter
```
Write an internal newsletter of 400 words.
Topics: [LIST]. Tone: informal but professional.
Structure: engaging intro, 1 paragraph per topic, closing.
```

### 10. Complaint response
```
You are the customer service manager. Respond to this complaint:
"[COMPLAINT TEXT]"
Acknowledge the inconvenience, briefly explain the cause: [CAUSE],
propose the solution: [SOLUTION]. Empathetic tone. Max 150 words.
```

### 11. Event invitation
```
Write an invitation for [EVENT TYPE] on [TOPIC].
Date: [DATE], Venue: [VENUE], Duration: [DURATION].
Target: [WHO]. Include: brief program, registration link.
Tone: [formal/enthusiastic]. Max 200 words.
```

### 12. Slack/Teams message
```
Rewrite this Slack message to be clearer and more concise:
"[ORIGINAL MESSAGE]"
Must be: max 3 lines, requested action clearly stated, direct tone.
```

### 13. Professional bio
```
Write a professional bio for [PLATFORM: LinkedIn/website/conference].
Role: [ROLE]. Company: [COMPANY]. Specializations: [LIST].
Tone: [first person/third person]. [N] words.
```

### 14. Effective email subject line
```
Suggest 5 email subject lines for an email that [PURPOSE].
Recipient: [WHO]. Tone: [TONE].
Requirements: max 8 words, specific, compelling to open.
```

### 15. Response to a commercial proposal
```
I received a commercial proposal for [SERVICE].
Cost: [PRICE]. Write a response to: [negotiate/accept/decline].
Points to mention: [POINTS]. Professional tone. Max 200 words.
```

## Analysis and Research (16-28)

### 16. Document summary
```
Summarize the following document in [N] key points.
Audience: [WHO]. Highlight: [ASPECTS].
Format: numbered list, each point 1-2 sentences.
Conclude with: "Action required: [yes/no and which]"
[PASTE DOCUMENT]
```

### 17. SWOT analysis
```
Create a SWOT analysis for [SUBJECT]. Context: [INDUSTRY/MARKET].
5 points per quadrant with brief explanation.
Conclude with 3 prioritized strategic recommendations.
```

### 18. Vendor/option comparison
```
Compare these options for [DECISION]:
A: [DESC] — B: [DESC] — C: [DESC]
Criteria (weighted 1-5): [LIST OF CRITERIA AND WEIGHTS].
Weighted decision matrix + justified recommendation.
```

### 19. Feedback analysis
```
Analyze this feedback: [PASTE]
For each: sentiment, theme, urgency.
Summary: recurring themes, critical issues, strengths, 3 actions.
```

### 20. Quick market research
```
You are a market analyst. Briefing on [MARKET/INDUSTRY]:
1. Size and trends  2. Key players  3. Typical target
4. Barriers to entry  5. Opportunities  6. Tech trends
Indicate where information may not be up to date.
```

### 21. Meeting preparation
```
I am about to meet [WHO] to discuss [TOPIC].
My role: [ROLE]. Goal: [GOAL].
Prepare for me: 5 key questions, 3 likely objections with responses,
useful data to have ready, proposed agenda with time allocations.
```

### 22. Competitor analysis
```
Compare [MY COMPANY] with competitors [A, B, C] on:
price, quality, service, innovation, market share.
Identify our competitive advantage and 2 vulnerabilities.
Format: table + written analysis.
```

### 23. Quick due diligence
```
I need to evaluate [COMPANY/PARTNER/VENDOR].
Give me a checklist of 10 aspects to verify,
with specific questions for each and red flags to look for.
```

### 24. Regulatory summary
```
Explain in simple terms (for non-lawyers) the regulation [NAME]
and its practical impacts for a company in [INDUSTRY].
Format: 5 key points + 3 actions to take.
Note when it is necessary to consult a lawyer.
```

### 25. Text-based KPI dashboard
```
Here are my KPIs for the month: [LIST OF KPIs WITH VALUES].
Targets: [TARGETS]. Previous month: [VALUES].
Create a performance analysis: for each KPI indicate status
(green/yellow/red), trend, comment. Summary in 5 lines.
```

### 26. Cost-benefit analysis
```
Evaluate the costs and benefits of [INITIATIVE/INVESTMENT].
Estimated cost: [AMOUNT]. Expected benefits: [LIST].
Timeframe: [PERIOD]. Calculate estimated ROI and payback period.
Identify 3 risks and 3 success factors.
```

### 27. Trend spotting
```
Identify 5 emerging trends in the [INDUSTRY] sector for the next 12 months.
For each trend: description, potential impact (high/medium/low),
suggested action for my company. Cite sources if possible.
```

### 28. Process audit
```
Analyze this process: [PROCESS DESCRIPTION].
Identify: bottlenecks, redundancies, risks, automation
possibilities. Propose 3 improvements with estimated impact.
```

## Productivity (29-40)

### 29. Structured to-do list
```
Extract the action items from the following text:
[PASTE TEXT]
Format: - [ ] Action (priority: high/medium/low) — deadline.
Group by project. Sort by priority.
```

### 30. SOP (Standard Operating Procedure)
```
Create an SOP for [PROCESS]. Who executes it: [ROLE]. Frequency: [WHEN].
Structure: purpose, prerequisites, step-by-step procedure (numbered),
success criteria, troubleshooting. Imperative tone.
```

### 31. Meeting minutes from notes
```
Transform these notes into professional meeting minutes:
[PASTE NOTES]
Format: date, attendees, points discussed, decisions made,
actions (with responsible person and deadline), next meeting.
```

### 32. Adapted translation
```
Translate this text into [LANGUAGE]. Do not translate literally:
adapt the tone to the [COUNTRY] market. Register: [TYPE].
Flag the adaptation choices. [PASTE TEXT]
```

### 33. Excel formula
```
I have a spreadsheet with columns: [DESCRIPTION].
I need a formula that: [WHAT IT SHOULD DO].
Provide: formula, where to place it, explanation, example with sample data.
```

### 34. Email template (series)
```
Create 5 email templates for [SITUATION]:
1. [TYPE 1]  2. [TYPE 2]  3. [TYPE 3]  4. [TYPE 4]  5. [TYPE 5]
For each: subject line + body (max 100 words). Placeholders: [NAME], [DATE].
```

### 35. Onboarding plan
```
Create a 30-day onboarding plan for a new [ROLE] in the [DEPARTMENT] department.
Table: week, activities, responsible person, objective, expected output.
First 3 days in more detail.
```

### 36. Project checklist
```
Create a complete checklist for [PROJECT TYPE].
Phases: initiation, planning, execution, monitoring, closure.
For each phase: 5-8 activities with suggested responsible person.
```

### 37. FAQ for team/clients
```
Create a FAQ document for [CONTEXT] with 15 questions.
Organize by category. Answers: max 3 sentences each, clear.
Include questions that people don't know they have.
```

### 38. Sales call script
```
Create a script for a sales call to [CLIENT TYPE].
Product/service: [WHAT]. Structure: opening, discovery (3 questions),
value presentation, objection handling (3 common objections),
closing with CTA. Tone: [TONE]. Estimated duration: [N] minutes.
```

### 39. Meeting agenda
```
Create an agenda for a [DURATION] meeting on [TOPIC].
Participants: [WHO]. Goal: [DECISION/ALIGNMENT].
For each item: allocated time, responsible person, expected output.
Include 5 min at the start for alignment and 5 at the end for next steps.
```

### 40. Survey/questionnaire response
```
I need to fill out this questionnaire for [PURPOSE]:
[PASTE QUESTIONS]
Context about my company: [INFORMATION].
Generate professional and consistent answers. Where data is missing, indicate [TO BE COMPLETED].
```

## Creativity and Strategy (41-50)

### 41. Structured brainstorming
```
You are an expert consultant in [INDUSTRY]. Problem: [DESCRIPTION].
Constraints: [BUDGET/TIME/RESOURCES]. Generate 10 ideas.
For each: name, description (2 sentences), cost (low/medium/high),
impact (1-5), time. Sort by impact/cost. 2 "out of the box" ideas.
```

### 42. Naming
```
Generate 10 names for [TYPE: project/product/event] about [TOPIC].
Target: [WHO]. Tone: [TYPE]. Language: [LANGUAGE].
For each name: meaning and pros/cons. Max [N] words per name.
```

### 43. Elevator pitch
```
Write a 30-second pitch (~80 words) for [PRODUCT/SERVICE/IDEA].
Target: [WHO]. Structure: problem, solution, benefit, CTA.
Create 3 versions: formal, enthusiastic, conversational.
```

### 44. Presentation structure
```
Create the structure of a [N]-slide presentation on [TOPIC].
Audience: [WHO]. Duration: [MINUTES].
Per slide: title + 3-4 bullets + visual suggestion.
```

### 45. Data storytelling
```
Here is my data: [DATA]. Transform it into a compelling narrative
for [AUDIENCE]. Use the framework: initial situation, challenge,
action taken, result achieved. Max 300 words.
```

### 46. Scenario analysis
```
We are evaluating [DECISION]. Analyze 3 scenarios:
optimistic, realistic, pessimistic.
For each: probability, impact, mitigation actions.
Final recommendation.
```

### 47. Priority matrix
```
I have these initiatives: [LIST].
Create an urgency/importance matrix (Eisenhower).
For each: classification, rationale, suggested action.
Table format.
```

### 48. Quarterly OKRs
```
Define 3 OKRs for the [DEPARTMENT] department for the next quarter.
Context: [CURRENT SITUATION, CHALLENGES].
Each Objective with 3 measurable Key Results.
Include specific metrics and numerical targets.
```

### 49. Risk register
```
Create a risk register for [PROJECT/INITIATIVE].
10 risks with: description, probability (1-5), impact (1-5),
residual risk, mitigation action, responsible person.
Sort by residual risk in descending order.
```

### 50. Project retrospective
```
Conduct a retrospective on [PROJECT/PERIOD].
What went well: [SUCCESSES]. What didn't work: [PROBLEMS].
Analyze the root causes of the problems. Propose 5 concrete actions
for the next cycle. Format: keep/stop/start.
```

## The emergency meta-prompt

When you don't know how to formulate a prompt:
```
I need to [GOAL] for [CONTEXT]. My audience is [WHO].
I don't know how to ask you to help me in the best way.
Ask me 3 questions to understand what I need,
then propose the optimal prompt.
```
