## Bonus Exercise: The Meta-Prompt

If you have time, try this powerful approach:

```
I need to [GOAL] for [CONTEXT].
I don't know how to ask you to help me in the best way.
Ask me 3 questions to better understand what I need,
then propose the optimal prompt to achieve the result.
```

**Did it work? Was the prompt suggested by the AI any good?**

## Summary: My Favorite Techniques

After the exercises, check the techniques you found most useful:

- [ ] Role-playing (assigning a role)
- [ ] Few-shot (providing examples)
- [ ] Chain-of-thought (step-by-step reasoning)
- [ ] Structured output (specifying the format)
- [ ] Constraints (length, tone, language)
- [ ] Decomposition (breaking down into sub-tasks)
- [ ] Iteration (refining after the first response)
- [ ] Meta-prompt (asking the AI to help you ask)
