# 50 Prompt per l'Ufficio

**Corso AI Basics — Modulo 6**
*Raccolta pronta all'uso per il lavoro quotidiano*

---

## Come usare questa raccolta

Ogni prompt e pronto da copiare e incollare. Sostituisci i segnaposti tra [PARENTESI] con i tuoi dati. Funziona con ChatGPT, Claude e la maggior parte dei modelli open.

---

## Comunicazione (1-15)

### 1. Risposta a email ricevuta
```
Ho ricevuto questa email: "[INCOLLA EMAIL]"
Scrivi una risposta che [OBIETTIVO].
Tono: [formale/cordiale/assertivo]. Max 150 parole.
```

### 2. Email di follow-up
```
Scrivi un'email di follow-up cortese a [NOME/RUOLO].
Contesto: [SITUAZIONE, es: gli ho inviato una proposta 5 giorni fa].
Obiettivo: ottenere [COSA]. Tono: professionale ma non insistente.
Max 100 parole.
```

### 3. Sollecito pagamento
```
Scrivi un sollecito di pagamento per la fattura n. [NUM] di [IMPORTO]
scaduta il [DATA]. Primo sollecito: tono cortese e collaborativo.
Menziona le modalita di pagamento. Max 120 parole.
```

### 4. Email di presentazione aziendale
```
Scrivi un'email di presentazione della nostra azienda [NOME]
a un potenziale cliente nel settore [SETTORE].
Servizi principali: [LISTA]. Proponi un incontro conoscitivo.
Tono: professionale, orientato al valore. Max 200 parole.
```

### 5. Ringraziamento post-meeting
```
Scrivi un'email di ringraziamento dopo un meeting con [CHI].
Riassumi i punti chiave discussi: [PUNTI].
Conferma i prossimi passi: [AZIONI]. Max 150 parole.
```

### 6. Comunicazione interna (annuncio)
```
Scrivi un annuncio interno per comunicare [NOVITA] al team.
Dettagli: [COSA CAMBIA, QUANDO, PERCHE].
Tono: positivo e chiaro. Includi FAQ: anticipa 3 domande.
Max 250 parole.
```

### 7. Rifiuto cortese
```
Scrivi un'email per rifiutare cortesemente [RICHIESTA/PROPOSTA].
Motivazione: [PERCHE]. Suggerisci un'alternativa se possibile.
Tono: rispettoso e professionale. Max 100 parole.
```

### 8. Post LinkedIn
```
Crea un post LinkedIn su [ARGOMENTO]. Target: [CHI].
Stile: [storytelling / dato statistico / lista / domanda aperta].
120 parole. Hook iniziale + CTA finale + 3 hashtag.
```

### 9. Newsletter interna
```
Scrivi una newsletter interna di 400 parole.
Temi: [LISTA]. Tono: informale ma professionale.
Struttura: intro accattivante, 1 paragrafo per tema, chiusura.
```

### 10. Risposta a reclamo
```
Sei il responsabile clienti. Rispondi a questo reclamo:
"[TESTO RECLAMO]"
Riconosci il disagio, spiega brevemente la causa: [CAUSA],
proponi la soluzione: [SOLUZIONE]. Tono empatico. Max 150 parole.
```

### 11. Invito a evento
```
Scrivi un invito per [TIPO EVENTO] su [TEMA].
Data: [DATA], Luogo: [LUOGO], Durata: [DURATA].
Target: [CHI]. Includi: programma sintetico, link registrazione.
Tono: [formale/entusiasta]. Max 200 parole.
```

### 12. Messaggio Slack/Teams
```
Riscrivi questo messaggio per Slack in modo piu chiaro e conciso:
"[MESSAGGIO ORIGINALE]"
Deve essere: max 3 righe, azione richiesta evidente, tono diretto.
```

### 13. Bio professionale
```
Scrivi una bio professionale per [PIATTAFORMA: LinkedIn/sito/conferenza].
Ruolo: [RUOLO]. Azienda: [AZIENDA]. Specializzazioni: [LISTA].
Tono: [prima persona/terza persona]. [N] parole.
```

### 14. Oggetto email efficace
```
Suggerisci 5 oggetti email per una mail che [SCOPO].
Destinatario: [CHI]. Tono: [TONO].
Requisiti: max 8 parole, specifico, che invogli ad aprire.
```

### 15. Risposta a proposta commerciale
```
Ho ricevuto una proposta commerciale per [SERVIZIO].
Costo: [PREZZO]. Scrivi una risposta per: [negoziare/accettare/rifiutare].
Elementi da menzionare: [PUNTI]. Tono professionale. Max 200 parole.
```

## Analisi e ricerca (16-28)

### 16. Riassunto documento
```
Riassumi il seguente documento in [N] punti chiave.
Destinatario: [CHI]. Evidenzia: [ASPETTI].
Formato: lista numerata, ogni punto 1-2 frasi.
Concludi con: "Azione richiesta: [si/no e quale]"
[INCOLLA DOCUMENTO]
```

### 17. Analisi SWOT
```
Crea un'analisi SWOT per [SOGGETTO]. Contesto: [SETTORE/MERCATO].
5 punti per quadrante con spiegazione breve.
Concludi con 3 raccomandazioni strategiche prioritizzate.
```

### 18. Confronto fornitori/opzioni
```
Confronta queste opzioni per [DECISIONE]:
A: [DESC] — B: [DESC] — C: [DESC]
Criteri (con peso 1-5): [LISTA CRITERI E PESI].
Matrice decisionale pesata + raccomandazione motivata.
```

### 19. Analisi feedback
```
Analizza questi feedback: [INCOLLA]
Per ciascuno: sentiment, tema, urgenza.
Riepilogo: temi ricorrenti, criticita, punti di forza, 3 azioni.
```

### 20. Ricerca di mercato rapida
```
Sei un analista di mercato. Briefing su [MERCATO/SETTORE]:
1. Dimensione e trend  2. Player principali  3. Target tipico
4. Barriere all'ingresso  5. Opportunita  6. Trend tech
Indica dove le info potrebbero non essere aggiornate.
```

### 21. Preparazione meeting
```
Sto per incontrare [CHI] per parlare di [TEMA].
Mio ruolo: [RUOLO]. Obiettivo: [OBIETTIVO].
Preparami: 5 domande chiave, 3 obiezioni probabili con risposta,
dati utili da avere pronti, proposta di agenda con tempi.
```

### 22. Analisi competitor
```
Confronta [MIA AZIENDA] con i competitor [A, B, C] su:
prezzo, qualita, servizio, innovazione, market share.
Identifica il nostro vantaggio competitivo e 2 vulnerabilita.
Formato tabella + analisi testuale.
```

### 23. Due diligence rapida
```
Devo valutare [AZIENDA/PARTNER/FORNITORE].
Fammi una checklist di 10 aspetti da verificare,
con domande specifiche per ciascuno e red flag da cercare.
```

### 24. Sintesi normativa
```
Spiega in modo semplice (per non giuristi) la normativa [NOME]
e i suoi impatti pratici per un'azienda di [SETTORE].
Formato: 5 punti chiave + 3 azioni da intraprendere.
Nota quando serve consultare un legale.
```

### 25. KPI dashboard testuale
```
Ho questi KPI del mese: [LISTA KPI CON VALORI].
Target: [TARGET]. Mese precedente: [VALORI].
Crea un'analisi performance: per ogni KPI indica status
(verde/giallo/rosso), trend, commento. Riepilogo in 5 righe.
```

### 26. Analisi costi-benefici
```
Valuta costi e benefici di [INIZIATIVA/INVESTIMENTO].
Costo stimato: [IMPORTO]. Benefici attesi: [LISTA].
Timeframe: [PERIODO]. Calcola ROI stimato e payback period.
Identifica 3 rischi e 3 fattori di successo.
```

### 27. Trend spotting
```
Identifica 5 trend emergenti nel settore [SETTORE] per i prossimi 12 mesi.
Per ogni trend: descrizione, impatto potenziale (alto/medio/basso),
azione suggerita per la mia azienda. Cita fonti se possibile.
```

### 28. Audit di processo
```
Analizza questo processo: [DESCRIZIONE PROCESSO].
Identifica: colli di bottiglia, ridondanze, rischi, possibilita
di automazione. Proponi 3 miglioramenti con impatto stimato.
```

## Produttivita (29-40)

### 29. To-do list strutturata
```
Dal seguente testo estrai le azioni da fare:
[INCOLLA TESTO]
Formato: - [ ] Azione (priorita: alta/media/bassa) — scadenza.
Raggruppa per progetto. Ordina per priorita.
```

### 30. SOP (procedura operativa)
```
Crea una SOP per [PROCESSO]. Chi la esegue: [RUOLO]. Frequenza: [QUANDO].
Struttura: scopo, prerequisiti, procedura passo-passo (numerata),
criteri di successo, troubleshooting. Tono imperativo.
```

### 31. Verbale riunione da appunti
```
Trasforma questi appunti in un verbale professionale:
[INCOLLA APPUNTI]
Formato: data, partecipanti, punti discussi, decisioni prese,
azioni (con responsabile e scadenza), prossima riunione.
```

### 32. Traduzione adattata
```
Traduci questo testo in [LINGUA]. Non tradurre letteralmente:
adatta il tono al mercato [PAESE]. Registro: [TIPO].
Segnala le scelte di adattamento. [INCOLLA TESTO]
```

### 33. Formula Excel
```
Ho un foglio con colonne: [DESCRIZIONE].
Serve una formula che: [COSA DEVE FARE].
Fornisci: formula, dove posizionarla, spiegazione, esempio con dati fittizi.
```

### 34. Template email (serie)
```
Crea 5 template email per [SITUAZIONE]:
1. [TIPO 1]  2. [TIPO 2]  3. [TIPO 3]  4. [TIPO 4]  5. [TIPO 5]
Per ciascuno: oggetto + corpo (max 100 parole). Segnaposti: [NOME], [DATA].
```

### 35. Piano di onboarding
```
Crea un piano onboarding di 30 giorni per un nuovo [RUOLO] nel reparto [REPARTO].
Tabella: settimana, attivita, responsabile, obiettivo, output atteso.
Primi 3 giorni piu dettagliati.
```

### 36. Checklist di progetto
```
Crea una checklist completa per [TIPO PROGETTO].
Fasi: avvio, pianificazione, esecuzione, monitoraggio, chiusura.
Per ogni fase: 5-8 attivita con responsabile suggerito.
```

### 37. FAQ per team/clienti
```
Crea un documento FAQ per [CONTESTO] con 15 domande.
Organizza per categoria. Risposte: max 3 frasi ciascuna, chiare.
Includi domande che le persone non sanno di avere.
```

### 38. Script chiamata commerciale
```
Crea uno script per una chiamata commerciale a [TIPO CLIENTE].
Prodotto/servizio: [COSA]. Struttura: apertura, discovery (3 domande),
presentazione valore, gestione obiezioni (3 obiezioni comuni),
chiusura con CTA. Tono: [TONO]. Durata stimata: [N] minuti.
```

### 39. Agenda riunione
```
Crea un'agenda per una riunione di [DURATA] su [TEMA].
Partecipanti: [CHI]. Obiettivo: [DECISIONE/ALLINEAMENTO].
Per ogni punto: tempo allocato, responsabile, output atteso.
Includi 5 min iniziali per allineamento e 5 finali per next step.
```

### 40. Risposta a survey/questionario
```
Devo compilare questo questionario per [SCOPO]:
[INCOLLA DOMANDE]
Contesto sulla mia azienda: [INFORMAZIONI].
Genera risposte professionali e coerenti. Dove mancano dati, indica [DA COMPLETARE].
```

## Creativita e strategia (41-50)

### 41. Brainstorming strutturato
```
Sei un consulente esperto di [SETTORE]. Problema: [DESCRIZIONE].
Vincoli: [BUDGET/TEMPO/RISORSE]. Genera 10 idee.
Per ciascuna: nome, descrizione (2 frasi), costo (basso/medio/alto),
impatto (1-5), tempo. Ordina per impatto/costo. 2 idee "fuori dagli schemi".
```

### 42. Naming
```
Genera 10 nomi per [TIPO: progetto/prodotto/evento] su [TEMA].
Target: [CHI]. Tono: [TIPO]. Lingua: [LINGUA].
Per ogni nome: significato e pro/contro. Max [N] parole per nome.
```

### 43. Pitch elevator
```
Scrivi un pitch di 30 secondi (~80 parole) per [PRODOTTO/SERVIZIO/IDEA].
Target: [CHI]. Struttura: problema, soluzione, beneficio, CTA.
Crea 3 versioni: formale, entusiasta, conversazionale.
```

### 44. Struttura presentazione
```
Crea la struttura di una presentazione di [N] slide su [ARGOMENTO].
Pubblico: [CHI]. Durata: [MINUTI].
Per slide: titolo + 3-4 bullet + suggerimento visuale.
```

### 45. Storytelling dati
```
Ho questi dati: [DATI]. Trasformali in una narrativa avvincente
per [PUBBLICO]. Usa lo schema: situazione iniziale, sfida,
azione intrapresa, risultato ottenuto. Max 300 parole.
```

### 46. Analisi scenari
```
Stiamo valutando [DECISIONE]. Analizza 3 scenari:
ottimistico, realistico, pessimistico.
Per ciascuno: probabilita, impatto, azioni mitigazione.
Raccomandazione finale.
```

### 47. Matrice priorita
```
Ho queste iniziative: [LISTA].
Crea una matrice urgenza/importanza (Eisenhower).
Per ciascuna: classificazione, motivazione, azione suggerita.
Formato tabella.
```

### 48. OKR trimestrali
```
Definisci 3 OKR per il reparto [REPARTO] per il prossimo trimestre.
Contesto: [SITUAZIONE ATTUALE, SFIDE].
Ogni Objective con 3 Key Results misurabili.
Includi metriche specifiche e target numerici.
```

### 49. Risk register
```
Crea un risk register per [PROGETTO/INIZIATIVA].
10 rischi con: descrizione, probabilita (1-5), impatto (1-5),
rischio residuo, azione di mitigazione, responsabile.
Ordina per rischio residuo decrescente.
```

### 50. Retrospettiva progetto
```
Conduci una retrospettiva su [PROGETTO/PERIODO].
Cosa e andato bene: [SUCCESSI]. Cosa non ha funzionato: [PROBLEMI].
Analizza le cause root dei problemi. Proponi 5 azioni concrete
per il prossimo ciclo. Formato: keep/stop/start.
```

## Il meta-prompt di emergenza

Quando non sai come formulare un prompt:
```
Devo [OBIETTIVO] per [CONTESTO]. Il mio pubblico e [CHI].
Non so come chiederti di aiutarmi al meglio.
Fammi 3 domande per capire cosa mi serve,
poi proponi il prompt ottimale.
```
