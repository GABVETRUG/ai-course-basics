Con la 23.26.4

La macro di tabella entra nella CTE

La macro della slide Oracle

create or replace macro dept_totals ( hired_after date ) is
  select department_id, count(*) emp# from hr.employees
  where  hire_date > hired_after group by all;

In giallo la novità

with recenti as (
  select * from dept_totals(date '2017-01-01')
)
select * from recenti
order  by emp# desc, department_id;

Su 23.26.3 lo stesso risultato arriva con una inline view al posto della CTE.

Fonte: All Things SQL, “How to create views with parameters in Oracle AI Database” · risultato calcolato su 23.26.3

È la novità vera: secondo il blog Oracle All Things SQL, dalla 23.26.4 le macro si possono usare nella clausola WITH. dept_totals è la vista con parametro della slide di Oracle: conta, per reparto, gli assunti dopo la data indicata. Il risultato è stato calcolato su 23.26.3 chiamando la stessa macro, in forma PL/SQL, dentro una inline view con lo stesso ORDER BY: per costruzione è identico. La riga con reparto nullo è il dipendente senza reparto assunto dopo il 1° gennaio 2017.
