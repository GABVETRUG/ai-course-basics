Fino alla 23.26.3

Una macro dentro una CTE dava ORA-64630

Macro di tabella

with recenti as (
  select * from dept_totals(date '2017-01-01')
)
select * from recenti;

ORA-64630: unsupported use of SQL macro: use of SQL macro inside WITH clause is not supported

Macro scalare

with nomi_z as (
  select formatted_name(first_name, last_name) nome
  from   hr.employees
  where  contains_z(last_name)
)
select * from nomi_z;

ORA-64630: unsupported use of SQL macro: use of SQL macro inside WITH clause is not supported

Vale per le macro di tabella e scalari, anche per quelle definite al volo con WITH FUNCTION.

Eseguito su Oracle AI Database 26ai Free 23.26.3 · macro in forma PL/SQL (CREATE FUNCTION … SQL_MACRO)

Il messaggio dell’errore è esplicito: use of SQL macro inside WITH clause is not supported. Il limite scatta quando la macro viene chiamata nella sottoquery che definisce la CTE. Verificato su 23.26.3 con la macro di tabella dept_totals, con le macro scalari formatted_name e contains_z, e anche con una macro scalare definita con WITH FUNCTION e poi usata dentro una CTE: in tutti i casi ORA-64630. Le macro sono quelle delle slide di Oracle, scritte nella forma PL/SQL perché CREATE MACRO arriva solo con la 23.26.4.
