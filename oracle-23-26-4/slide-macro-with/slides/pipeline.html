La query della slide, riscritta a passi

Ogni passo ha un nome

with primi_reparti as (
  select * from get_3_rows(hr.departments)
),
assunti_dal_2015 as (
  select * from dept_totals(date '2015-01-01')
)
select department_id, department_name, emp#
from   primi_reparti
left   join assunti_dal_2015 using (department_id)
order  by department_id;

È la join della slide Oracle tra get_3_rows e dept_totals, con i passi dichiarati nella WITH.

Senza ORDER BY in get_3_rows i tre reparti possono cambiare.

Risultato calcolato su 23.26.3 con le due macro in inline view · la stessa query con la WITH dava ORA-64630

La query della slide Oracle su CREATE MACRO metteva in join get_3_rows(hr.departments) e dept_totals(date '2015-01-01'). Con la 23.26.4 ogni macro può diventare un passo con un nome nella WITH, e la query finale si legge come una frase. Il risultato è stato calcolato su 23.26.3 con le due macro in inline view e ORDER BY department_id: coincide con quello della slide (reparti 10, 20 e 30). get_3_rows non ha ORDER BY: restituisce tre righe qualsiasi, quindi in un altro database i reparti possono essere diversi.
