Macro usa e getta con WITH FUNCTION

Definita e usata nella stessa query

with function top3 ( t dbms_tf.table_t )
  return varchar2 sql_macro(table) is
begin
  return 'select * from t fetch first 3 rows only';
end;
select * from top3(hr.jobs)
/

OK su 23.26.3

JOB_IDJOB_TITLE

AD_ASSTAdministration Assistant
  • Nessun oggetto nel database e nessun privilegio CREATE
  • In SQL*Plus si chiude con / e non con ;
  • Usata dentro una CTE: ORA-64630 su 23.26.3

Eseguito su Oracle AI Database 26ai Free 23.26.3

Un’alternativa comoda per script e demo: la macro si definisce con WITH FUNCTION e vive solo dentro la query, senza creare oggetti e senza privilegi di CREATE. Su 23.26.3 funziona sia per le macro di tabella (top3 su hr.jobs restituisce AD_PRES, AD_VP, AD_ASST) sia per quelle scalari, purché siano usate nella query principale. Una macro WITH FUNCTION usata dentro una CTE dà lo stesso ORA-64630: con la 23.26.4 il divieto cade per le macro in generale, ma questo caso specifico va provato. In SQL*Plus un’istruzione con WITH FUNCTION va terminata con la barra.
