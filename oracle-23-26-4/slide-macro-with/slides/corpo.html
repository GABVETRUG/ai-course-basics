Una WITH dentro il corpo della macro

Parametro fuori dalla WITH · OK

-- corpo di top_earners ( n number )
with ranked as (
  select last_name, salary,
    dense_rank() over (order by salary desc) rnk
  from hr.employees
)
select * from ranked where rnk <= n

Parametro dentro la WITH

-- corpo di dept_staff ( p_dept number )
with d as (
  select employee_id, last_name from hr.employees
  where  department_id = p_dept
)
select count(*) n from d

select * from dept_staff(50);
ORA-00904: "P_DEPT": invalid identifier

Con una inline view al posto della WITH il parametro viene sostituito: il reparto 50 dà 45.

Eseguito su 23.26.3 con le macro in forma PL/SQL · sulla 23.26.4 da riprovare

Qui il caso è rovesciato: la WITH sta nel testo restituito dalla macro. Su 23.26.3 funziona finché il parametro scalare è usato fuori dalla sottoquery della WITH: top_earners(3) restituisce i quattro stipendi dei primi tre livelli (King, Yang, Garcia, Singh), anche se la query che la chiama ha a sua volta una WITH. Se il parametro è dentro la sottoquery della WITH non viene sostituito, e la query fallisce con ORA-00904 sul nome del parametro: è un limite noto, descritto anche sul blog SQLORA. La soluzione verificata è una inline view al posto della WITH (reparto 50: 45 dipendenti, reparto 60: 5). Il post di Oracle parla di un grosso aggiornamento delle macro nella 23.26.4: questo caso va riprovato sulla nuova release.
